# Acceptance Test Checklist

- [ ] All 6 cameras show a live image
- [ ] Large monitor and TV display the live view
- [ ] Recording is active on all cameras
- [ ] Playback of a recent recording works
- [ ] Overwrite option is enabled
- [ ] Remote viewing works from mobile (Wi-Fi and mobile data)
- [ ] PC 1 and PC 2 have internet and network access
- [ ] Printer prints from both PCs
- [ ] Ticketing system issues and prints tickets correctly
- [ ] Devices keep their IPs after router/XVR restart
- [ ] System recovers after a power cut
- [ ] Default passwords changed
